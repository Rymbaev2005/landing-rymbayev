# CyberSafe — курс по кибербезопасности

## Тема

Одностраничный лендинг онлайн-курса по кибербезопасности. Сохранены исходные разделы, тексты и визуальный стиль проекта лабораторной работы №2.

## Структура

* `index.html` — разметка страницы и Tailwind utility-классы.
* `style.css` — только декоративные стили для фоновой сетки, градиентов и иллюстрации щита.

## Технологии

* HTML5
* Tailwind CSS через Play CDN (`https://cdn.tailwindcss.com`)
* Flexbox и CSS Grid через utility-классы Tailwind
* Адаптивные префиксы `sm:`, `md:` и `lg:`

Tailwind подключён непосредственно в `<head>` через Play CDN; устанавливать зависимости через npm не требуется. Основная раскладка, размеры, отступы и адаптивность заданы utility-классами в HTML.

## Почему этот инструмент

Tailwind CSS удобен тем, что основные стили и адаптивная раскладка находятся прямо в HTML, поэтому сразу видно, как оформлен каждый элемент. Play CDN позволяет подключить Tailwind одной строкой, не устанавливая дополнительные пакеты для учебной страницы. Utility-классы помогают быстро менять отступы, цвета, Flexbox и сетки без написания большого количества собственных правил. Responsive-префиксы позволяют постепенно менять интерфейс от телефона к планшету и компьютеру. При этом длинные наборы классов могут сделать HTML менее компактным, а для особых декоративных элементов всё ещё нужен небольшой CSS. В отличие от Bootstrap, Tailwind не предлагает готовые компоненты с заранее заданным внешним видом, а даёт более гибкую настройку отдельных элементов. По сравнению с Sass/SCSS и БЭМ здесь меньше отдельных файлов и соглашений по именованию, но важно следить за читаемостью классов в разметке.
