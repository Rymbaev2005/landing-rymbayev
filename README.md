# landing-rymbayev
# CyberSafe — курс по кибербезопасности

## Тема

Одностраничный адаптивный лендинг для онлайн-курса по кибербезопасности.

## Ссылка

[Открыть сайт](https://example.com)

> Замените `https://example.com` на ссылку на опубликованный сайт или GitHub Pages.

## Что сделано

* Создан адаптивный лендинг курса по кибербезопасности.
* Использованы **HTML5 и CSS3** без фреймворков и конструкторов.
* Реализована семантическая HTML-разметка: `header`, `nav`, `main`, `section`, `article`, `form`, `footer`.
* Добавлены блоки:

  * главный экран;
  * информация о курсе;
  * программа обучения;
  * целевая аудитория;
  * форма записи;
  * footer.
* Добавлены заголовки `h1`, `h2`, `h3`.
* Создана форма с полями имени, email и сообщения.
* Для полей формы добавлены `label` и `required`.
* В `<head>` добавлены `title`, `meta description`, `viewport` и favicon.
* Реализована адаптивная версия для мобильных устройств от **375 px** и десктопных экранов до **1280 px**.
* Добавлены hover-эффекты и современное оформление в тематике кибербезопасности.

## Технологии

* HTML5
* CSS3
* CSS Media Queries
